## Objective

Add the Model Context Protocol (MCP) SDK as a production dependency to enable Orchestra to expose its functionality as an MCP server. This is the foundational task for the entire MCP Server feature.

The MCP SDK provides:
- STDIO transport for AI agent communication
- Tool definition and registration APIs
- Standard error codes and response types
- Server lifecycle management

## Implementation Details

### Step 1: Add Dependency

Add to the `dependencies` section of `package.json`:

```json
{
  "dependencies": {
    "@modelcontextprotocol/sdk": "^0.6.0"
  }
}
```

**Important**: This MUST be in `dependencies`, NOT `devDependencies`, because the MCP server will be a production feature of Orchestra.

### Step 2: Install

Run:
```bash
npm install
```

### Step 3: Verify Installation

The package should be importable. You can verify by checking that TypeScript recognizes it:
```bash
npx tsc --noEmit
```

### About the MCP SDK

The `@modelcontextprotocol/sdk` package provides:

```typescript
// Key exports you'll use in later tasks (just for context)
import { Server } from "@modelcontextprotocol/sdk/server/index.js";
import { StdioServerTransport } from "@modelcontextprotocol/sdk/server/stdio.js";
```

You do NOT need to write any code using these imports for this task - just add the dependency.
