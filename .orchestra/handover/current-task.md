## Objective

Add the `@modelcontextprotocol/sdk` dependency (version `^0.6.0` or compatible) to `package.json`. This SDK is required for implementing the MCP (Model Context Protocol) server that will expose Orchestra operations as tools for AI agents.

## Background

The MCP Server (Phase 2 of Orchestra) enables AI agents to interact with Orchestra through standardized MCP tools. The SDK provides:
- MCP server and client infrastructure
- STDIO transport for process-based communication
- Tool definition and registration APIs
- Standard error handling for MCP protocol
