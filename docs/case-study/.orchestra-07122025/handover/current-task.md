## Objective

Add the Model Context Protocol (MCP) SDK as a dependency to the Orchestra project. This SDK enables Orchestra to expose its operations as MCP tools for AI agents like GitHub Copilot.

## Context

Orchestra is implementing an MCP server layer. The MCP SDK provides:
- Server and transport classes for STDIO communication
- Tool registration and handler patterns
- Error handling utilities
- Type definitions for MCP protocol
