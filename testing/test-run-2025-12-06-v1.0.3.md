## Issues Found

### Issue 1: No guidance when Orchestra not initialized

**Severity**: Medium  
**Status**: Open  
**Category**: UX/Onboarding

**Description**:
When Orchestra is not initialized in a workspace, there's no helpful guidance for agents/humans. Need either:
1. `orchestra status` to work gracefully and show setup instructions, OR
2. `orchestra guide` command that provides setup, usage, and first/next step guidance

**Current Behavior**:
- `orchestra status` fails with error if not initialized
- No clear path for new users/agents to understand what to do

**Expected Behavior**:
- Running `orchestra status` (or a new `orchestra guide` command) should:
  - Detect Orchestra is not initialized
  - Explain what Orchestra is
  - Show how to initialize (`orchestra init`)
  - Guide to next steps

**Proposed Solutions**:
1. **Option A**: Make `orchestra status` graceful - show "Not initialized" state with guidance
2. **Option B**: Create `orchestra guide` command for onboarding
3. **Option C**: Both - status shows state, guide shows detailed help

**Related**:
- `orchestra next` already provides guidance once initialized
- This is the pre-initialization equivalent

### Issue 2: current-task.md.hbs template has incorrect CLI commands

**Severity**: High  
**Status**: Fixed  
**Category**: Template/Documentation Mismatch

**Description**:
The `current-task.md.hbs` template (used to generate handovers) contains incorrect CLI commands that don't match the documented workflow in `docs/workflow/implement.md`.

**Discrepancies Found**:

| Section | Template Says | Workflow Says |
|---------|---------------|---------------|
| Before You Start | `orchestra status` | `orchestra validate-handover` (A-IMPL-00) |
| Pre-signal check | `orchestra accept-signal` | `orchestra pre-signal-check` (A-IMPL-09) |

**Impact**:
- Implementor agents receive handovers with wrong instructions
- Workflow doesn't match documented process
- `orchestra validate-handover` never gets called as mandated by A-IMPL-00
- `orchestra pre-signal-check` never gets called as mandated by A-IMPL-09

**Root Cause**:
Template was not updated when workflow documentation was finalized.

**Fix Applied**:
Updated `templates/common/templates/current-task.md.hbs` to use correct commands:
1. "Before You Start" section: `orchestra status` → `orchestra validate-handover`
2. Pre-signal check: `orchestra accept-signal` → `orchestra pre-signal-check`

**Files Changed**:
- `templates/common/templates/current-task.md.hbs`

### Issue 3: Template sync issue - Multiple template locations not updated

**Severity**: High  
**Status**: Fixed  
**Category**: Template Sync / Process Gap

**Description**:
Issue 2 fix was incomplete. The `current-task.md.hbs` template exists in MULTIPLE locations, and only one was fixed. Additionally, the `agent_readme.md` files (which guide implementors) were missing the mandatory `orchestra validate-handover` and `orchestra pre-signal-check` steps entirely.

**Locations Found**:

| File | Purpose | Status |
|------|---------|--------|
| `templates/common/templates/current-task.md.hbs` | Source template | Fixed in Issue 2 |
| `.orchestra/common/templates/current-task.md.hbs` | Sprint-local copy | **Was NOT fixed** |
| `.orchestra/handover/current-task.md` | Generated handover | Fixed in Issue 2 |
| `.orchestra/handover/agent_readme.md` | Implementor workflow guide | **Was missing steps** |
| `templates/handover/agent_readme.md` | Source agent readme | **Was missing steps** |

**agent_readme.md Issues**:
1. No "Step 0: Validate Handover" - implementors had no instruction to run `orchestra validate-handover`
2. No "Step 5: Pre-Signal Check" - implementors had no instruction to run `orchestra pre-signal-check`
3. Workflow steps were numbered 1-7, missing the critical validation bookends

**Fix Applied**:
1. Fixed `.orchestra/common/templates/current-task.md.hbs` with correct commands
2. Added "Step 0: Validate Handover" to both `agent_readme.md` files
3. Added "Step 5: Pre-Signal Check" to both `agent_readme.md` files
4. Renumbered workflow steps (now 0-8 instead of 1-7)

**Files Changed**:
- `.orchestra/common/templates/current-task.md.hbs`
- `.orchestra/handover/agent_readme.md`
- `templates/handover/agent_readme.md`

**Process Gap Identified**:
Need to review template sync process. When updating a template, ALL locations must be identified and updated:
1. Source templates in `templates/`
2. Sprint-local copies in `.orchestra/common/templates/`
3. Generated files in `.orchestra/handover/`

**Action Item**:
- [ ] Review full implementor workflow end-to-end
- [ ] Consider adding template sync validation to `orchestra prepare`
- [ ] Document template locations in TEMPLATE_REGISTRY.md
